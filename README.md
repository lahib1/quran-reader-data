# Quran Reader data

Translations and tafsirs for the Quran Reader app (https://github.com/lahib1/quran-app), converted into the app's
own file format and packed with gzip. The app downloads one pack at a time, checks it against the SHA-256 in
`catalogue.json`, and reads it offline from then on.

- Release `packs`: one asset per item and version, `<id>-<version>.pack`.
- Release `catalogue`: `catalogue.json`, the list of every item with its pack's address, size and SHA-256.

Each text is republished unchanged from its source, with its credit and terms below. The verses' Arabic is the
QPC Hafs text from the King Fahd Complex, as published by the Quranic Universal Library (https://qul.tarteel.ai).
